# User Guide

How-to walkthroughs for people *using* splashdown. The [README](../../README.md) is the main
manual and the authoritative spec; these pages go deeper on setups that need a step-by-step
guide. Written for humans: verbose and example-driven.

If you're working *on* splashdown instead, see [`../features/`](../features/overview.md) (what
each feature does) and [`../tech/`](../tech/overview.md) (how it's built). Agents don't load
this tree by default.

## Guides
- [monorepos.md](monorepos.md): setting up splashdown in multi-app workspaces (JS workspaces,
  RN/Expo, polyglot native + web, docker-compose services), and how `splash init` handles them.
